## Day 8 — AI-Powered Environmental Health Dashboard

### What I Built
A fully interactive Personal Environmental Health Analyzer dashboard
built entirely using Claude Artifacts — no coding required.

### What the Dashboard Includes
- AQI comparison charts for multiple cities
- PM2.5 and PM10 pollution charts
- Interactive city selector and filters
- Environmental Health Score (0-100)
- Air quality and water quality impact on health
- Personalized recommendations for daily actions

### What Surprised Me Most
Claude built a complete, working HTML application with charts,
filters, and animations just from a text prompt. No manual coding
needed at all.

### Key Learnings
- Claude Artifacts can generate full interactive web applications
- AI can combine data analysis + UI design + health insights in one output
- Prompt engineering determines the quality of the application built
- Claude can act as a Data Analyst, Designer, and Developer simultaneously

### Tool Used
Claude Artifacts — Claude's built-in feature to generate
interactive HTML/React applications directly in the chat interface
