Here's a practical roadmap to break into data science, whether you're starting from scratch or transitioning from another field.

## Phase 1: Foundations (2–4 months)
- **Math/stats**: Descriptive statistics, probability, hypothesis testing, linear algebra basics, intro calculus (for understanding gradients/optimization later)
- **Programming**: Python (preferred over R for most roles) — variables, loops, functions, data structures, then libraries: `pandas`, `numpy`
- **SQL**: Joins, aggregations, subqueries, window functions — this is non-negotiable, almost every DS job tests it

## Phase 2: Core Data Science Skills (3–5 months)
- **Data wrangling & visualization**: Cleaning messy data, `matplotlib`/`seaborn`/`plotly`, exploratory data analysis (EDA)
- **Machine learning fundamentals**: Regression, classification, decision trees, random forests, gradient boosting (XGBoost/LightGBM), clustering, using `scikit-learn`
- **Model evaluation**: Cross-validation, precision/recall/F1, ROC-AUC, overfitting/underfitting, bias-variance tradeoff
- **Statistics for experiments**: A/B testing, confidence intervals, p-values — critical for product-facing DS roles

## Phase 3: Build Real Projects (ongoing, 2–3 months focused)
- 3–5 portfolio projects using **real, messy datasets** (not just Titanic/Iris) — ideally solving a problem end-to-end: business question → data collection → cleaning → modeling → communicating results
- Put them on GitHub with clear README files explaining your reasoning, not just code
- Bonus: one project that mimics your target industry (finance, healthcare, e-commerce, etc.)

## Phase 4: Specialize & Go Deeper (3–6 months)
Pick a direction based on what excites you or what jobs you're targeting:
- **Analytics-leaning**: Advanced SQL, dashboarding (Tableau/Looker), experimentation design
- **ML engineering-leaning**: Deep learning basics (`PyTorch`/`TensorFlow`), model deployment, MLOps, Docker/cloud (AWS/GCP)
- **Research-leaning**: Deeper stats/math, NLP or computer vision, staying current with papers

## Phase 5: Job Search Prep (1–2 months, parallel to above)
- Practice SQL and Python coding challenges (LeetCode, StrataScratch)
- Prepare to explain your projects clearly — interviewers care more about your reasoning than fancy algorithms
- Practice "case study" style questions (product/business sense) if targeting product-analytics-heavy roles
- Network: LinkedIn, local meetups, Kaggle competitions for visibility

## Rough Timeline
- **Career switcher with technical background** (engineering, finance, science): 6–9 months
- **Complete beginner**: 12–18 months
- **Current job in adjacent field** (analyst, BI, SWE): 4–8 months, since you likely already have some pieces
