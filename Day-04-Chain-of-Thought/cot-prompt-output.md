## Step 3 & 4 — 6-Month Roadmap with Resources

### **Month 1: Python Mastery + Math Foundations**
**Goals:** Get fully comfortable with Python; start math basics
**Milestones:** Build 3-4 small Python programs (calculator, file organizer, simple automation script); comfortable with functions, loops, OOP

**Resources (Free):**
- YouTube: *CodeWithHarry* or *Corey Schafer* (Python full course)
- Math: *3Blue1Brown* (Essence of Linear Algebra series on YouTube — visual and intuitive)
- Practice: HackerRank (Python domain)

---

### **Month 2: NumPy, Pandas, Data Visualization + Stats**
**Goals:** Data handling and analysis skills
**Milestones:** Clean and analyze a real dataset (e.g., Titanic dataset on Kaggle); create visualizations

**Resources (Free):**
- YouTube: *Krish Naik* (Pandas/NumPy playlist), *StatQuest with Josh Starmer* (statistics concepts explained simply)
- Website: Kaggle "Learn" micro-courses (Pandas, Data Visualization)
- Practice: Kaggle datasets

---

### **Month 3: Classical Machine Learning**
**Goals:** Understand and implement ML algorithms
**Milestones:** Build 2-3 ML models from scratch and using scikit-learn (e.g., house price prediction, spam classifier)

**Resources (Free):**
- YouTube: *StatQuest* (algorithm intuition), *Krish Naik* (scikit-learn implementation)
- Website: Google's *Machine Learning Crash Course* (free, excellent)
- Book (free): "An Introduction to Statistical Learning" (ISLR, free PDF)

---

### **Month 4: Deep Learning Fundamentals**
**Goals:** Understand neural networks, start a framework (PyTorch recommended for learning clarity)
**Milestones:** Build a basic neural network from scratch (no framework) to understand backprop; then rebuild using PyTorch

**Resources (Free):**
- YouTube: *3Blue1Brown* (Neural Networks series), *freeCodeCamp* (PyTorch full course)
- Website: PyTorch official tutorials (pytorch.org)
- Course: fast.ai (Practical Deep Learning — free, project-first approach)

---

### **Month 5: Specialization (Choose CV or NLP) + Git/Deployment**
**Goals:** Go deeper into one domain; learn to deploy a model
**Milestones:** Build one solid project (image classifier OR text classifier); deploy it using Streamlit; push everything to GitHub

**Resources (Free):**
- YouTube: *Krish Naik* or *CampusX* (CNN/NLP specific playlists)
- Website: Hugging Face (free courses on NLP/Transformers)
- Tool: Streamlit (streamlit.io) for quick deployment
- Git: *freeCodeCamp Git & GitHub* video

---

### **Month 6: Portfolio, Competitions, and Job Readiness**
**Goals:** Consolidate everything into a portfolio; get real-world tested
**Milestones:** 
- Complete 2-3 polished projects on GitHub with good READMEs
- Participate in at least one Kaggle competition
- Build LinkedIn profile + resume tailored to ML roles
- Start applying to internships

**Resources (Free):**
- Kaggle Competitions (start with "Getting Started" ones)
- YouTube: resume/LinkedIn tips for tech roles (search "ML resume" recent videos)
- GitHub Pages (free portfolio site)
