## Day 10 — Personal Portfolio Website

### What I Built
A complete single-file personal portfolio website generated 
entirely using Claude — no manual coding required.

### Sections Included
- Hero with typing animation and social links
- About Me
- Skills with animated bars and tech tags
- Projects with cards and tech tags
- Achievements and Certifications
- Contact form with direct links
- Dark/Light mode toggle
- Mobile responsive design

### How I Built It
Used Claude as a full-stack web developer by providing my 
personal details, skills, projects, and design preferences 
in a structured prompt. Claude generated the complete HTML 
in one shot.

### Key Learnings
- Structured prompts with clear sections produce better outputs
- Claude can generate production-ready UI in a single prompt
- Personal branding + AI = professional portfolio in minutes
- Single-file HTML with Tailwind CDN needs zero setup to run
