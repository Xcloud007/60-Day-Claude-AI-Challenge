# Rupesh's Weekly Plan — 60-Day Claude AI Challenge

**Time budget:** 1.5–2 hrs/day · **Style:** short focused sessions, step-by-step, action over theory

---

## 1. The Daily Structure (pick 1.5–2 hr slot, same time each day)

Break it into 3 short blocks instead of one long grind — easier to protect on busy days.

| Block | Time | What |
|---|---|---|
| **Warm-up** | 10 min | Re-read today's challenge task. Note exactly what "done" looks like. |
| **Core work** | 60–75 min | Do the actual task in Claude (prompt engineering, skill-building, research task, etc.) |
| **Wrap-up** | 15–20 min | Save output as HTML → correct folder → push to GitHub (`Xcloud007/60-Day-Claude-AI-Challenge`) → tick it off |

If you only get 45 minutes on a hard day: skip warm-up, do a **scoped-down version** of core work, still wrap up. A half-done, saved, committed task beats a skipped one.

---

## 2. Weekly Rhythm

| Day | Focus |
|---|---|
| **Mon–Thu** | New challenge tasks (current day's task, on schedule) |
| **Fri** | New task **+ start catch-up** if you're behind |
| **Sat** | **Catch-up day** — dedicated to backlog (see below) |
| **Sun** | Light day: GitHub tidy-up, LinkedIn post, plan next week (30–45 min, not full session) |

This gives you one full buffer day (Sat) every week instead of letting missed days silently pile up.

---

## 3. Catch-Up System (for missed days)

1. **Cap the backlog.** Never let missed tasks exceed 3 at once. If you hit 3, Saturday is 100% catch-up — no new task that day.
2. **Triage before redoing.** For each missed day, ask: *quick win (<30 min) or full task?* Do quick wins first for momentum.
3. **Compress, don't skip.** For a backlogged task, do a leaner version (core deliverable only, skip extras) rather than skipping entirely — you want the GitHub commit and the learning rep.
4. **One missed day is normal.** Two in a row → flag it, use Saturday. Three+ → consider whether the daily time slot needs to move (see Section 5).

---

## 4. GitHub & LinkedIn Habit (Sunday, 30–45 min)

- [ ] Confirm every HTML file from the week is uploaded to the right per-task/per-stock folder in `Xcloud007/60-Day-Claude-AI-Challenge`
- [ ] Write 1 short LinkedIn post: what you built this week + 1 screenshot or link (2–3 sentences, not an essay)
- [ ] Glance at next week's challenge tasks so Monday isn't a cold start

---

## 5. Weekly Check-In (5 min, do this every Sunday)

Answer just 3 questions:
1. How many tasks did I complete on-time this week? ___ / 7
2. What made me miss a day (if any)? (time, energy, task difficulty, forgot)
3. One tweak for next week? (e.g., move slot earlier, shrink core block to 45 min)

This is the only "theory" part of the plan — keep it to 5 minutes, it's just a steering wheel, not a journal.

---

## 6. Quick Reference Card

- **Backlog limit:** 3 tasks max before mandatory catch-up
- **Minimum viable session:** 45 min (warm-up skipped, core scoped down, wrap-up always included)
- **Non-negotiable:** the wrap-up (save + push to GitHub) — this is what makes the portfolio real
- **Weekly buffer:** Saturday
- **Weekly reflection:** Sunday, 5 min, 3 questions
